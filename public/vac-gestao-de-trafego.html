O que é este aplicativo

Virando a Chave é uma agência de gestão de tráfego pago. Esta ferramenta interna (módulo "Gestão de Tráfego") é usada para acompanhar o desempenho das campanhas de anúncios (Google Ads e Meta Ads) que a agência gerencia para seus clientes.

Para que usamos o acesso ao Google Ads

Este aplicativo se conecta à API do Google Ads, com permissão apenas de leitura, para:

  • Consultar métricas de desempenho das contas de anúncio geridas pela agência (investimento, cliques, impressões, conversões);
  • Gerar relatórios automáticos de desempenho, enviados periodicamente aos clientes da agência via WhatsApp;
  • Verificar se as campanhas dos clientes estão ativas, para alertar a equipe caso alguma pare de rodar.

Não realizamos alterações em campanhas, orçamentos ou configurações de anúncios através desta integração — o acesso é somente para leitura de relatórios.

Quem tem acesso

O uso é restrito à equipe interna da Virando a Chave. Não é um produto disponibilizado a terceiros nem coleta dados de usuários finais dos anúncios.
